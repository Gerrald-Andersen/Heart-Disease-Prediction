# 📁 `data/` — Datasets for Heart Disease Prediction

This folder contains raw and processed datasets used throughout the **Heart Disease Prediction** pipeline.  
The data is sourced from Kaggle and cleaned/preprocessed before being used for model training and evaluation.

---

## 📦 Folder Structure

| Folder / File                     | Description                                                             |
|----------------------------------|-------------------------------------------------------------------------|
| `raw/heart_disease_raw.csv`       | Unprocessed dataset downloaded directly from Kaggle                     |
| `clean/heart_disease_clean.csv`   | Cleaned and preprocessed dataset ready for model training and evaluation |

---

## 🔄 Data Flow

1. **`heart_disease_raw.csv`**  
   - Contains the original patient health records with all features.  
   - Used as the source for preprocessing.

2. **`heart_disease_clean.csv`**  
   - Includes cleaned, encoded, and scaled features.  
   - Generated by the preprocessing notebook in the `src/notebooks/` folder.  
   - Ready to be fed into machine learning models.

---

## 🧠 Usage Notes

- The raw dataset is stored for reproducibility and reference.  
- The cleaned dataset is used as input for model training and evaluation.  
- Ensure that any updates to the raw data are reflected in the cleaned dataset through proper preprocessing.
